# Memoria del proyecto

Esta carpeta es la **memoria secundaria** de Claude para Swappit: lo que no está en el código pero hay que saber para trabajar bien (reglas, decisiones, contexto, historial). Claude la lee antes de trabajar y la actualiza cuando aprende algo nuevo. Vos también podés escribir acá: lo que agregues lo voy a tener en cuenta.

- [[Reglas de trabajo]]: cómo quiere Rafael que se trabaje.
- [[Decisiones]]: decisiones tomadas, con fecha y motivo.
- [[Equipo]]: quién es quién.
- [[Diseño y Figma]]: archivo de Figma, pantallas, fuentes.
- [[Entorno y herramientas]]: compus, carpetas, base de datos, cómo se prueba.
- [[Bitácora]]: qué se hizo y cuándo (lo más nuevo arriba).
- [[Pendientes y problemas]]: errores conocidos y lo que falta.

**Cómo se usa:** una nota por tema, con fecha en cada dato. Si algo deja de ser cierto se corrige o se tacha, no se deja contradictorio.
